# SkyTrack Geodata — Offline Reverse Geocoding

This directory contains CSV datasets used for offline reverse geocoding (GPS coordinates to City, State ZIP).

## Data Quality Notice

**These datasets are synthetic/approximate.** City coordinates are hand-curated reference
points (typically city center), not official municipal boundaries. ZIP centroid coordinates
are generated by applying geographic jitter around known city locations — they represent
approximate centroids, not USPS-defined boundaries. This is sufficient for nearest-neighbor
reverse geocoding on a kiosk display but should not be used for mailing, legal boundaries,
or precision GIS work.

No external APIs or licensed datasets are used. Everything is offline and self-contained.

## Files

| File | Rows | Description |
|------|------|-------------|
| `us_cities.csv` | ~836 | US cities: all state capitals + cities >50k population |
| `us_zip_centroids.csv` | ~7300 | Approximate ZIP code centroids across all 50 states + DC |

## Coverage

- All 50 US states + District of Columbia
- Alaska and Hawaii included
- Reasonable geographic distribution within each state

## Format

### us_cities.csv
```
city,state,lat,lon
Montgomery,AL,32.3792,-86.3077
```

### us_zip_centroids.csv
```
zip,state,lat,lon
01001,MA,42.3244,-71.0306
```

## How It Works

The `geocode_offline.py` module loads these files into memory and uses haversine distance
to find the nearest city and ZIP centroid for a given lat/lon coordinate. The result is
formatted as `City, ST ZIP`.

## Regenerating

Run the generator script:
```bash
python3 geodata/generate_geodata.py
```

The generator uses a fixed random seed (`random.seed(42)`) so output is deterministic.

## Installation

The `install.sh` script copies these files to `/var/lib/skytrack/geo/` on the target device.
