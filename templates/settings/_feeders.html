ADS-B receiver

The ADS-B stack installs dump1090-fa (the radio decoder) and PiAware (the FlightAware feeder) together. SkyTrack reads aircraft data from dump1090's local output — without it the map shows sample data only.

FlightRadar24 (optional add-on)

      

        FR24 is a separate feeder that shares your ADS-B data with
        FlightRadar24. It reads from the dump1090 output — install the
        ADS-B stack above first. After installing, you may need to run
        sudo fr24feed --signup via the super admin shell
        to complete the initial FR24 setup.
