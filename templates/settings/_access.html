{# Settings → Access #}

Admin password

Required for every sensitive action. Minimum 6 characters.

PIN optional

Alternate sign-in for the admin role. Leave blank and submit to remove the PIN entirely.

Session & lockout

How long admin stays signed in and how many failed attempts trigger a temporary lockout.

Hotspot password

Manage the WPA2 password from the Network section so you can see and regenerate it together with the SSID.
