Display

Settings for the on-device kiosk screen (HDMI / touchscreen).

SkyTrack ships in portrait (Rotate Right). Pick whichever matches how the screen is physically mounted. Takes effect at the next reboot.

Only affects the official Raspberry Pi 7" touchscreen (backlight via sysfs). HDMI monitors ignore this — use the monitor's own buttons. applies on reboot

0 = always on. The kiosk dims but never fully sleeps — touch or move the mouse to wake.

Controls the floating particle background on the dashboard. Set to Reduced or Off if the Pi feels sluggish.

How many background particles to draw. Lower = less CPU on a Pi.

Leave this on for normal appliance operation. Turn off only for debugging — when disabled, Chromium starts in a regular window. applies on reboot
