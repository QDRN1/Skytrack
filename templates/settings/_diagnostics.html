Reset onboarding

      

        Wipes the admin PIN and returns the device to the welcome
        screen so the first-boot setup flow can be re-run. This is a
        logical reset — hostapd, dnsmasq, Cloudflare tunnel, and
        sqlite data are all preserved. You will be logged out and
        prompted to set a new PIN.
